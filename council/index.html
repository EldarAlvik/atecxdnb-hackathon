3 wild cards
Objects with their own bank account

Huset har BankID (Opus) · The Building That Hires Its Own Caretaker (Astra) · BUY MYSELF (Sol). A house, building or machine that earns, saves and pays its own debts.

Recommendation: build the home scam guardian, using Fullmakt's hardware seal as its money guardrail. It's the strongest independent signal and the most direct hit on DNB's biggest consumer pain. The seal also gives judges a checkable moment: the scammer orders the device to release the payment, and it physically can't. The runner-up is DRYP, the cleanest physical demo of the lot: spill water, the valve turns, the claim is signed with a long press. Expect other teams at a DNB hackathon to pitch scam protection too. The agent plus the hardware seal is what sets this one apart.

How the agent runs: the board runs its own Wi-Fi firmware and calls a hosted agent API directly, with no laptop in between. It sends events and streams mic audio, and gets back speech, screen updates and motor commands. The agent service calls Claude with tools (hold payment, alert family, speak) behind a policy layer. Releasing money needs a seal signed on the device, which the agent can't forge. Full spec: docs/architecture.md

Hardware reality check (both rounds)

  • Not everything fits at once: the 14-port board has 12 module ports, so no build can use every part (Opus and DeepSeek both checked).
  • The agent lives off-board: the SDK talks to the board over USB serial, so the agent runs on a laptop or in the cloud and the board is its body. Wi-Fi needs extra firmware.
  • Voice is the main risk: the mic streams only a sound level by default. Speech capture needs a little custom firmware, with the laptop's mic as the fallback.
  • Sim-only parts: the camera, load cell and soil sensor have no firmware driver.
  • First build: it downloads about 2.4 GB of tools, so start it early.
  • Check before the stage: fraud-loss figures, the cabin count and the €30B fraud figure all came from model memory.
